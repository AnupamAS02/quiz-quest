# Brainer

This repository is worked on by a Brainer team. This file is on `brainer/work`, the one branch the team works on.

## How the team works here

- **Brainer doesn't host this code.** Hosting, deploys, domains, databases and keys are the owner's, wherever they run them today. Brainer has no copy of it.
- **One branch.** The team clones this repository, works on `brainer/work` and pushes only there. It never pushes to `main` or any other branch.
- **One pull request.** The team's work comes to `main` as a pull request from `brainer/work`. Only the owner merges it; the team never does. Once it's merged, `brainer/work` starts again from `main`.
- **Your own changes stay yours.** The team brings in what changes on the default branch before it builds on it.
